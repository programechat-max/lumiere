Lumiere — Yeni Kullanıcı Akış Arkaplanı

Gerçek kod karşılıkları: main.py, ai_core.py, store.ts. Sekmelerden akışları incele.

Kayıttan programlara genel yolculuk

flowchart TD
    A["📱 Kayıt / Giriş
POST /api/register → JWT"] --> B["📋 Onboarding Formu (9 adım)
hedef, kilo, yaş/boy, seviye, gün sayısı"]
    B --> C["🎥 Adım 7: Vücut Videosu (10-15 sn)
POST /api/onboarding/video"]
    C --> C1["(ops.) 🎤 Sesli Anlatım
POST /api/onboarding/voice"]
    C1 --> D["✅ Tamamla
PUT /api/profile + POST /api/onboarding/complete
→ video analizi kalıcı hafızaya"]
    D --> E["📝 Program Oluşturucu Anketleri"]
    E --> F["🏋️ Antrenman anketi bitti
POST /api/program-builder/workout"]
    F --> F1["🤖 generate_workout_program
split + egzersiz havuzu + AI"]
    E --> G["🥗 Beslenme anketi bitti
POST /api/program-builder/nutrition"]
    G --> G1["🤖 generate_meal_plan
besin havuzu + AI + makro doğrulama"]
    F1 --> H["📊 Uygulama: günlük antrenman + öğünler,
koç sohbeti, progress takibi"]
    G1 --> H

Onboarding bitince program üretimi beklemeye alınır; gerçek üretim Program Oluşturucu anket cevaplarıyla tetiklenir (boş bekleme yok, daha kişisel bağlam).

Antrenman programı üretimi (anket sonrası)

flowchart TD
    A["📝 Anket cevapları"] --> B["💾 Profil alanlarına yazılır"]
    B --> C["👤 Profil: deneyim, hedef, odak, sakatlık"]
    C --> D["🧮 Bilimsel parametreler
level → MEV/MAV/MRV + periodizasyon + RPE"]
    D --> E["📅 Split Planlayıcı
build_split (PPL / Upper-Lower / Full Body)"]
    E --> F["🏋️ Akıllı Egzersiz Seçici
grup başı en iyi 8 hareket, filtreli"]
    F --> G["🔬 Küratörlü Kanıt (PMID'li)"]
    G --> H["📉 Zayıf Bölge Tespiti"]
    H --> I["📄 Odak Grup PubMed Canlı Blok"]
    I --> J["🧠 GEMINI: kilitli hareket havuzu +
MAV kuralları + stretch prensibi → JSON"]
    J --> K["🔗 Kütüphane Uzlaştırma
bilinmeyen → pending_review"]
    K --> L["💾 WorkoutProgram tabloları → uygulama"]

Kritik: AI boş hayal kurmaz — hareketler kilitli kütüphane havuzundan, gün dağılımı bilimsel split şablonundan, kanıtlar PMID'lidir.

Beslenme planı üretimi

flowchart TD
    A["📝 Anket cevapları"] --> B["💾 Profil alanlarına yazılır"]
    B --> C["👤 Hedefler: kalori/protein/karb/yağ
+ dietary_notes"]
    C --> D["🥗 Doğrulanmış Besin Havuzu
42 temel + 59 TR kürasyon + USDA"]
    D --> E["🍽️ Öğün sayısı: anket tercihi
(yoksa 3-5 kılavuzu)"]
    E --> F["🧠 GEMINI: Türk mutfağı kuralları,
%5 sapma, protein dağılımı"]
    F --> G["🔍 Makro Doğrulama
verify_and_fix_meal_plan:
%5+ sapan porsiyon düzeltilir"]
    G --> H{"💾 Kaydet?"}
    H -- "evet" --> I["📦 replace_meal_plan → günlük plan"]
    H -- "hayır" --> J["📝 Taslak (onay akışı)"]

Besin makroları AI'ya güvenilmez: USDA + TR kürasyonundan doğrulanmış 100g değerlerinden yeniden hesaplanır.

Sesli anlatım (opsiyonel kol)

flowchart TD
    A["🎤 Ses kaydı (webm/ogg)"] --> B["💾 user_audio/"]
    B --> C["📝 transcribe_audio → metin"]
    C --> D["🧠 extract_profile_from_transcript
profile_updates + summary + memory_summary"]

Kullanıcının sesli anlattığı kısıtlamalar/sakatlıklar/rutin profil alanlarına işlenir; sonraki tüm üretimlerde hesaba katılır.
